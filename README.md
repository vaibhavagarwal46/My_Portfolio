## About

This is my personal portfolio website showcasing my projects, skills, education, and experience as a **B.Tech Computer Science Engineering** student at SRMS College of Engineering & Technology, Bareilly. The site features a **cyberpunk/tech-noir aesthetic** with a fully interactive 3D animated background powered by Three.js.

---

## Features

- **Interactive 3D Background** — Animated particle field (2,800 particles), wireframe icosahedrons, floating torus rings, and a perspective grid — all rendered with Three.js and reacting to mouse movement in real-time
- **Typing Animation** — Hero section cycles through roles: AI Developer, ML Engineer, Full Stack Dev, Python Expert, Computer Vision Dev
- **Custom Cursor** — Glowing cyan dot with a lagging outer ring; changes to purple on hover
- **Animated Skill Bars** — Bars fill with a smooth animation when scrolled into view
- **Scroll-Triggered Reveals** — Every section fades up as it enters the viewport using IntersectionObserver
- **Scroll Progress Bar** — Gradient progress bar at the top tracks reading progress
- **Fully Responsive** — Adapts cleanly to mobile, tablet, and desktop
- **Functional Contact Form** — Opens the user's email client pre-filled with their message
- **All Links Work** — GitHub repos, LinkedIn, email, phone, and Google Maps location all linked correctly
- **Cyberpunk Aesthetic** — Dark theme with cyan, purple, and gold accents; scanlines and noise overlay for depth
- **Zero Dependencies** — No npm, no build tools — just three files and a CDN link for Three.js

### How to run this 

No installation or build step needed — just open the file!

```bash
# Clone the repository
git clone https://github.com/vaibhavagarwal46/portfolio.git

# Navigate into the folder
cd portfolio

# Open in browser (macOS)
open index.html

# Open in browser (Linux)
xdg-open index.html

# Open in browser (Windows)
start index.html
```

Or simply drag and drop `index.html` into your browser.
